# Optional lens library and casting guardrails

Load only when /ng-rethink was explicitly invoked, especially Creative or Deep. No persona is a literal participant. Named thinkers represent methods plausibly associated with their documented work, not invented quotations or a claim they would endorse the result. Choose **unique failure axes**, not a parade of famous names.

| Lens | Operational method | Question it owns | Tension partner |
|---|---|---|---|
| First principles — Feynman/Musk-inspired | separate physics/mathematics from conventions; remove assumptions | Which requirement could be deleted while preserving the outcome? | Systems Reliability |
| Product minimalism — Jobs/Ive-inspired | user journey, end-to-end experience, eliminate affordance clutter | Which complexity does the operator unnecessarily pay for? | Expansionist |
| Working backwards — Bezos-inspired | customer/field acceptance first, then dependencies | What would constitute a result customers would actually adopt? | First Principles |
| High reliability — Rickover-inspired | invariant, boundary, operating envelope, traceable responsibility | What subtle failure would a field operator detect too late? | Fast Experiment |
| Inversion — Munger/Taleb-inspired | failure-first assumptions, incentive and tail risks | How do we guarantee failure, and which exposure is irreversible? | Expansionist |
| Software craft — Carmack/Torvalds-inspired | small working slices, explicit interfaces and deterministic tests | Can the simplest testable system demonstrate the entire mechanism? | Systems |
| Scientific falsification | hypothesis vs result, controls, sources and error bars | What observation would disprove this design? | Futurist |
| System dynamics — Meadows-inspired | flows, feedback loops, delays and leverage points | Which apparent local fix destabilizes the whole system? | Product |
| Constraint breaker — TRIZ | identify technical contradictions; separate conflicting requirements in time/space | What design removes the tradeoff instead of averaging it? | Risk |
| Lateral innovator — SCAMPER | substitute, combine, adapt, modify, reuse, eliminate, reverse | What distant domain already solved an analogous problem? | Reliability |
| Long-horizon futurist | second/third order, path dependence and option value | What would make this architecture obsolete in three years? | Executor |
| Outsider / ethnographer | fresh eyes and observed use in situ | What unstated practice makes the design fail in reality? | Architect |
| Security / abuse reviewer | threat modeling, least privilege and boundary crossing | Which privilege or input can become an unintended capability? | Feature Expansion |
| Performance reviewer | complexity, bottlenecks, workload shape and profiled costs | What cannot meet requirements at expected scale? | Minimalist |
| Finance / commercial analyst | total lifecycle cost, incentives, capital allocation, opportunity cost | Is the most technically elegant approach economically inferior? | Futurist |
| Editor / clarity reviewer | decision readability and actionable scope | Could a new engineer correctly implement this from the handoff? | Architect |

## Default council

Default Standard seating: First Principles, Product/Operator, Systems/Reliability, Contrarian/Inversion, Craftsman/Executor. If the domain demands, swap a seat (not merely add seats) to include its expert failure axis. Up to seven for Deep; always ensure a **polarity pair**. Example tensions: experimental speed versus reliability, operator simplicity versus capability, capital efficiency versus optionality, visionary expansion versus falsification.

## Custom casting

If a user requests historical thinkers by name, make a short map: **name -> documented framework -> concrete test or design question**. Where a requested person's actual methods are unknown or unclear, say so and use a generic seat rather than fabricating knowledge. Do not imply that actual people participated, were contacted or provided independent judgments.

## Synthesis guardrails

- The chair is a synthesis role, not a sixth voter.
- Independent provider calls require permission and provenance; roles inside one model are simulated lenses.
- No majority vote trumps a verified failed hard constraint.
- Preserve dissent even if only one seat holds it.
- Reuse Nuclear-grade's review-panel and evidence-custody machinery for trust-bearing verdicts.
