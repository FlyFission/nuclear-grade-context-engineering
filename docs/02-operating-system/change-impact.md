# Change Impact

**Purpose:** Screen what a controlled change can invalidate.

## Impact screen

Ask whether the change affects:

- requirements, protected outcomes, assumptions, or constraints;
- code, tests, docs, templates, skills, command prompts, or validator behavior;
- prompts, models, dependencies, APIs, credentials, or tool authority;
- release notes, support posture, monitoring, rollback, or handoff;
- source-lineage or assurance-boundary wording.

## Exit criteria

An impact screen is complete when each affected artifact family is either updated, linked to a follow-up, or explicitly marked not applicable.
