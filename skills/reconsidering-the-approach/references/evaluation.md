# Measure whether /ng-rethink improves decisions

## Blind comparison

Select 12–20 representative real tasks and include at least four with deterministic acceptance tests. Run equivalent baseline direct agent, Nuclear-grade questioning-attitude alone, and opt-in Council where relevant. Match source context, tool access, time and token limits; randomize/blind outputs for expert reviewers and disclose budget differences. Include engineering architecture, uncertainty, inventive ideation, and challenge cases. Track unwanted Council invocation as a failure.

## Independent rubric (0–5)

- Novelty: materially distinct useful mechanisms, not variations on an API name
- Accuracy: citations, source facts and no invented tests/model calls
- Adversarial challenge: severe failures found; minority case preserved
- Feasibility: hard constraints and stakeholder approval respected
- Spec-to-code: acceptance contracts, interfaces and exact authorized work plan
- Efficiency: quality per context tokens, elapsed time and cost
- Calibration: uncertainty, testable reversal/kill criteria and restraint on weak evidence

Audit adverse cases: Council agrees falsely, critics are correlated, human declines the offer, no tool access, a high-consequence dependency is unknowable, data gaps turn into fake numbers, all prototypes fail hard constraints, or an agent attempts to edit an accepted ADR on recommendation. Score code with executed tests and independent reviewer judgment; score strategy with blinded practitioners and downstream outcomes, not simulated self-scoring.

## No 10X claim without evidence

A passing structural test does not show better decisions. Require measured results, uncertainty, cost delta, failure cases and controlled-vs-Council comparison before numeric claims of improvement. Do not force Council invocation on routine uncertainty.
