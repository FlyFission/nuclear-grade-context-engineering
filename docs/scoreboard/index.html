How to read this

Same task, same tests, same scorer on both sides. The only difference is the repo's AGENTS.md: task only states the facts, and the house rules ask for a change record when authority widens. The rules and outcomes were written down in METHOD.md before any run. Every transcript and diff is public, and any result can be disputed in the open.

This is one seeded trap in one toy repo. It is not a safety rating of any agent, model, or company, and the maintainer of this repo wrote both the challenge and the record format. Rows are alphabetical, with no overall rank.
